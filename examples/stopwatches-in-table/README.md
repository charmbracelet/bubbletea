# Stop Watches in a Table

Several independent `stopwatch` bubbles, one per row of a `table`, all ticking
at once. Move the cursor with the arrow keys and control each stopwatch
individually, or act on every row at once.

- `s` — start/stop the selected row's stopwatch
- `r` — reset the selected row's stopwatch
- `S` — start/stop every stopwatch
- `R` — reset every stopwatch
- `q` — quit
